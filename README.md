# FruitFun 🍎🍌🥭

FruitFun is a colorful educational web application designed to help users learn about different fruits in a fun and interactive way.

## Features

* Colorful homepage with fruit images
* Large, easy-to-use navigation tabs
* Detailed information about 9 popular fruits:

  * Apple
  * Banana
  * Mango
  * Orange
  * Grapes
  * Pineapple
  * Watermelon
  * Strawberry
  * Kiwi
* Educational content about fruits and their importance
* Interactive quiz at the end of each fruit page
* FAQ section
* Customer helpline section
* Simple login form
* Responsive design using HTML, CSS, and JavaScript

## Purpose

FruitFun was created to make learning about fruits engaging and enjoyable for students, children, and anyone interested in healthy eating. The app provides nutritional information, fun facts, and quizzes to reinforce learning.

## Technologies Used

* HTML5
* CSS3
* JavaScript

## How to Use

1. Open the website in a web browser.
2. Navigate through the fruit tabs.
3. Read the information about each fruit.
4. Complete the quiz at the bottom of each fruit page.
5. Explore the FAQ and customer support sections.

## Future Improvements

* More fruits and categories
* Quiz scoring system
* User accounts and progress tracking
* Fruit games and activities
* Dark mode support
